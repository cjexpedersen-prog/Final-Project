# Final-Project
Final project for summer 2026 web development

This project can be used to fetch recipe data and view recipies from the publicly availble ProjectData repository.

After downloading the zip, open the MainPage HTML file
  In the file is a search function which may be used to view entries in the Entries.json file of the Recipies folder, and a filter button which displays and can search through filters found in the Tags.json file, clicking on the filter button removes it from the list and creates an element on the form displaying that it is being used to filter the search results (in an OR manner, rather than AND).

  The search Term "all" may be used to veiw all recipies in the index
